# KerbalCraft

[English](README.md) | **Русский**

**Майнкрафт прямо в окне Kerbal Space Program.** Выходишь на поверхность Муны — и ты Стив: блоки,
кирка, факелы, TNT, крафт, всё настоящее; но небо, солнце, тени, ракеты и сам грунт — из KSP.
Можно построить дом на Минмусе, прыгать на семь блоков вверх при гравитации Муны, пнуть ракету
так, что она завалится набок, и взорвать её TNT.
# РАБОТАЕТ И НА ПИРАТКЕ!!!
Проект сделан на основе [SkyCraft](https://github.com/chasmlol/SkyCraft) (Minecraft ⇄ Skyrim, MIT):
Fabric-мод и протокол общей памяти оттуда, а «хост» (то, что в SkyCraft делал SKSE-плагин для Skyrim)
написан заново как плагин KSP на C#.

![Кербал на фоне майнкрафтовских блоков.](docs/screenshot.png)

> **Статус: 0.1.** Запускалось и тестировалось в игре автором на Windows, KSP 1.12.x и Minecraft 26.3.
> Проверено: протокол Java↔C# синхронизирован (`tools/check_protocol.py`), математика систем координат
> (`tools/test_frame_math.py`). Версия ранняя: возможны ошибки, особенно на других конфигурациях.
> Баги и наблюдения по ним — в Issues.

## Что умеет

| | |
|---|---|
| Мир | Блоки Minecraft рисуются **мешами Unity внутри сцены KSP**: их освещает солнце KSP, они отбрасывают и принимают тени, их закрывают детали ракет и рельеф. Не наложенная картинка. |
| Планеты | Площадка («site») — плоский участок Minecraft-мира, касательный к поверхности в точке, где вы вышли. Постройки хранятся в мире Minecraft и ждут вас на месте; на каждой планете и в каждом месте свои. |
| Гравитация | Гравитация тела из KSP масштабирует физику Стива: на Муне (1,63 м/с²) тот же прыжок ≈ в 6 раз выше, на Минмусе (0,49) — в 20. Падение: безопасная высота растёт, урон от падения — по скорости. |
| Рельеф | Земля под ногами — настоящий рельеф KSP (по лучам в загруженные коллайдеры, дальше — по функции высоты планеты). Холмы, кратеры, склоны. |
| Ракеты | Каждая деталь ракеты рядом — «подставка»-сущность в Minecraft с хитбоксом. Удар → **импульс на детали** (`AddForceAtPosition`): пинок валит ракету. Длинные детали делятся на несколько хитбоксов. |
| Взрывы | TNT (и всё, что взрывается в Minecraft) толкает детали ракет радиальным импульсом. |
| Столкновения | Стив ходит по корпусам и стоит на посадочных опорах (треугольники коллайдеров деталей). Поставленные блоки — настоящие препятствия для ровера и пнутой ракеты (BoxCollider’ы). |
| Опасности | Деталь, влетевшая в Стива на скорости, и струя работающего двигателя — урон по сердцам. |
| Вода | Океаны Кербина: Стив плавает; уровень воды — настоящий уровень моря KSP. |
| Вход на борт | Посмотреть на ракету и нажать `G` — вы снова пилот этого корабля. |
| Всё остальное | Крафт, инвентарь, меню паузы, чат, мультиплеер по сети (e4mc) — обычный Minecraft 26.3. |

## Управление

* **Insert** — войти / выйти из режима Стива (корабль должен стоять на земле или плавать; можно и на EVA).
* **Esc** — меню паузы Minecraft. **G** — подняться на борт корабля, на который смотрите.
* Остальное — как в Minecraft (WASD, пробел, ЛКМ — бить/копать, ПКМ — ставить, E — инвентарь, 1–9, F5…).
* В режиме Стива управление KSP заблокировано (`InputLockManager`), курсор захвачен.

Стартовый набор (наследие SkyCraft + космос): железная броня, камень, брёвна, стекло, лестницы, двери, фонари, верстак, ведро воды, стрелы, золотые яблоки и **16 TNT с огнивом**.

## Установка

Нужны: **Windows**, KSP 1.12.x, аккаунт Microsoft с Minecraft: Java Edition.

1. Распакуйте `KerbalCraft-<версия>.zip` в папку KSP (получится `GameData/KerbalCraft/…`).
2. Запустите KSP. В главном меню плагин сам распакует и запустит Minecraft (портативный Prism
   Launcher). При первом запуске войдите в Microsoft-аккаунт — Prism сам скачает Minecraft 26.3 и Java.
3. В полёте посадите корабль и нажмите **Insert**.

Без бандла: поставьте мод `kerbalcraft-fabric-<версия>.jar` + Fabric API в свой Minecraft 26.3 и
запускайте его вручную (`-Dkerbalcraft.startHidden=true` прячет окно).

## Сборка из исходников

```
python tools/check_protocol.py                       # Proto.cs ⇄ Proto.java, раскладка памяти
python tools/test_frame_math.py                      # системы координат

# плагин KSP (нужна установка KSP 1.12.x для ссылок на Assembly-CSharp/UnityEngine)
dotnet build ksp/KerbalCraft.csproj -c Release -p:KSPDir="C:\Games\KSP"
#   -> ksp/GameData/KerbalCraft/Plugins/KerbalCraft.dll

# мод Minecraft
cd fabric && gradlew build                           # или tools\launch_minecraft.bat для dev-клиента

# шейдеры (необязательно, но красивее) — см. ksp/Unity/Editor/BuildShaderBundle.cs
# релиз
powershell -File tools\package.ps1 -KspDir "C:\Games\KSP" -ShaderBundle path\to\kerbalcraft.shaders
```

`ksp/src/Proto.cs` **генерируется** из `Proto.java` (`tools/gen_proto_cs.py`) — руками не править.

### Шейдеры

Без `GameData/KerbalCraft/Shaders/kerbalcraft.shaders` плагин использует шейдеры KSP
(`KSP/Alpha/Cutoff`, …): всё рисуется, но без оттенков биомов (трава серая), ambient occlusion и
уровней света Minecraft. Бандл собирается в Unity **2019.4.18f1** из трёх `.shader` в
`ksp/Unity/Shaders` (меню *KerbalCraft → Build shader bundle*). Готового бандла в репозитории нет:
собрать его без Unity нельзя.

## Настройки

`GameData/KerbalCraft/KerbalCraft.cfg` — клавиши, `mouseScale`, `kickImpulse` (сила пинка),
`explosionImpulse`, `tetherMeters`, `overlayScale` (для 4K), радиусы и т.д. Все ключи необязательны.

## Известные риски (проверьте первыми)

Эти места написаны по памяти об API KSP/Unity. Часть из них проверена в игре, но не все. Если что-то работает не так, смотрите здесь в первую очередь:

1. **Сборка C#**: возможны опечатки и несовпадение имён API (`ControlTypes.*`, `GameEvents.onHideUI`, `ScaledSpace.LocalToScaledSpace`…). Компилятора в среде разработки не было.
2. **Камера** (`Pose.cs`, `CameraDriver`): подмена позиции/поворота камер KSP в `Camera.onPreCull` по именам `Camera 00/01`, `Camera ScaledSpace`, `GalaxyCamera`. Если небо/планета рисуются неверно — смотрите имена камер в вашей версии.
3. **Скорость мыши**: `Input.GetAxisRaw("Mouse X")` в KSP может давать не пиксели; подгоните `mouseScale`.
4. **Направление струи двигателя** (`Hazards.cs`): принято, что выхлоп идёт вдоль `thrustTransform.forward`; если урон получаете спереди двигателя, поменяйте знак.
5. **Отзеркаливание**: Minecraft правосторонний, Unity левосторонний; корень рендера — `LookRotation` + `localScale.x = -1`. Если мир выглядит зеркальным (надписи наоборот) — проверьте этот переход (`SiteFrame.cs`, `WorldRenderer.cs`).
6. **Статические коллайдеры блоков** движутся вместе с площадкой (вращение планеты), что для PhysX — «двигающаяся статика». Если вредит — `blockColliders = false`.
7. **Режим EVA-якоря** (`followWithEva`) экспериментальный и выключен.

## Чего нет по сравнению с SkyCraft

Скиллы и бой Skyrim, Discord-присутствие, разрушение ландшафта (`TRI_DIGGABLE`): рельеф PQS
нельзя «продырявить». Код копания унаследован, но неактивен (хост не помечает треугольники).
Воксели (`ColBlock`) отправляются только для рельефа; корпуса кораблей — только треугольниками
(игрок их чувствует, брошенные предметы и стрелы — нет). Предметы на земле падают с «земной»
гравитацией. Время суток Minecraft не синхронизируется (освещение даёт KSP).
